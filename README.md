# המתמטיקה של שירה — המקור

הגיבוי המלא של האתר, **כולל כלי הבנייה** שאינם עולים לאתר החי.

* אתר חי: <https://noanono1.github.io/shira-math/>
* ענף `main` באותו מאגר = האתר הבנוי בלבד (מה שנפרס).
* הענף הזה (`source`) = אותו דבר **ועוד** `build/` — סקריפטי הבנייה, מילון החיפוש,
  בודקי הרינדור והאימות, וסקריפט הפריסה.

## הגייטים לפני פרסום

```
build/render_check.py --no-pdf      # שגיאות קונסולה · KaTeX · תמונות שבורות
build/verify_everything.py          # תיבות תשובה · איזון סוגריים · ראיות ויזואליות
build/build_search_index.py         # אינדקס החיפוש
build/deploy.sh                     # פריסה (מעלים קודם את CACHE ב-sw.js!)
```

צילומי הבדיקה (`build/shots/`) לא נכללים כאן — הם נוצרים מחדש בכל הרצה.
